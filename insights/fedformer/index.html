趋势与季节性分解提供结构先验，频域表示帮助模型捕捉长周期模式。碰到制度变化或局部冲击时，过去的周期能解释多少未来需要重新测量。

研究方法与证据

维度评估
数据 / 来源论文使用六个公开真实数据集：ETTm2、Electricity、Exchange、Traffic、Weather、ILI；附录还给出 ETT full benchmark。覆盖能源、经济、交通、天气和疾病，领域广度较好。
样本与边界数据集以规则采样的公开时间序列为主，训练/验证/测试按 7:1:2 划分。边界是这些数据相对干净，不能完全代表企业生产系统中常见的缺失、口径变更、突发业务事件和跨系统延迟。
变量 / 测量主指标是 MSE 和 MAE；分布分析使用 Kolmogorov-Smirnov test；复杂度用训练/测试时间复杂度和 memory complexity 表述。指标适合论文比较，但不足以衡量业务损失。
识别或评估策略与 Autoformer、Informer、LogTrans、Reformer 等 Transformer 系列基线比较，预测长度覆盖 96、192、336、720；ILI 使用 24、36、48、60。设置基本沿用 Autoformer，有利于同场比较。

结论的适用条件

批判维度具体问题对结论的影响
隐性假设时间序列存在可压缩频域结构，并且随机 modes 能稳定覆盖关键频率。若数据由强突发、制度切换、一次性事件主导，频域稀疏性可能变弱，模型优势下降。
隐性假设预测输出与输入分布相似是好事。对稳定周期序列成立；对 regime shift、政策变更、供应链中断等场景可能成为保守偏差。
替代解释性能提升可能主要来自 decomposition，而非频域 attention。消融显示 FEB/FEA 有贡献，但 decomposition 与频域模块交互复杂，贡献边界仍需更多独立实验。

值得继续追问

  1. 一次突然的结构变化发生后，哪些频率分量仍值得沿用？
  2. 如果把 MSE/MAE 换成库存缺口成本、能源采购偏差成本或产线停滞风险，FEDformer 的优势是否仍然成立？
  3. 对弱周期、强事件冲击、结构突变频繁的企业数据，随机 Fourier modes 是否仍优于更显式的因果变量或状态空间方法？
