节点反复接收邻居状态并更新自己，待状态稳定后再读出预测。理解这个早期框架，既要看信息如何传播，也要看保证收敛所付出的表达与计算代价。

研究方法与证据

维度评估
数据 / 来源实验覆盖三类任务：合成子图匹配、Mutagenesis 化合物分类和合成网页排序。优点是能展示节点分类、图分类和排序的通用性；限制是两个任务含合成设计，真实业务图复杂度更高。
样本与边界子图匹配使用随机图并插入小子图；Mutagenesis 有 230 个硝基芳香化合物；网页排序使用 5000 个节点的随机网页图且只监督 50 个训练节点。样本足以说明模型可工作，但不足以证明大规模工业级稳健性。
变量 / 测量主要测量包括分类准确率、相对误差、学习误差、梯度计算时间、前向和反向迭代次数。测量与模型主张匹配，但缺少现代意义上的消融、跨数据集泛化和统计置信区间。
识别或评估策略论文用 FNN 对照说明仅靠节点标签不如同时使用拓扑和标签；用线性与非线性 GNN 对比说明非线性转移函数表达能力更强；用复杂度曲线验证部分理论分析。

结论的适用条件

批判维度具体问题
隐性假设图结构已知且质量足够好；节点和边标签能承载主要语义；邻域扩散足以表达任务机制；收敛稳定性比短路径可塑性更重要。
替代解释子图匹配和 Mutagenesis 的收益可能来自使用拓扑信息，而不一定来自固定点 GNN 这一特定实现；graph kernels、ILP 或后来的图卷积方法也可能获得相似收益。
可反证路径在大规模异构动态图、强异配图、边关系未知图或需要长程组合推理的任务上，如果固定点迭代收敛慢、表达力不足或被有限层 message passing 稳定超越，则论文的实践外推需收缩。

值得继续追问

  1. 一个局部状态要经历多少次更新，远端信号才足以改变其输出？
  2. 如果把压缩映射约束放松，模型表达力提升和收敛风险之间的临界点在哪里？
  3. 对企业架构中的系统依赖图而言，哪些节点状态应该被建模为可学习变量，哪些只能作为治理规则显式输入？
