记忆的载体、服务的任务以及写入和遗忘规则，决定同一段经历何时能再次帮上忙。这份综述提供了比较不同记忆设计的共同坐标。

研究方法与证据

维度评估
概念清晰度较强。 论文先定义代理策略、环境状态、轨迹与记忆状态，再用形成、演化、检索算子描述耦合关系；对代理记忆与大模型记忆、检索增强生成、上下文工程的差异给出作用范围和时间性解释。弱点是这些边界在混合系统中仍需主观判断。
文献边界覆盖极广且更新到 2025 年末，包含大量方法、基准和框架。但正文未说明数据库、关键词、检索日期、去重、纳入排除、质量评级和双人编码流程，也没有提供文献流图。因此它是“综合性叙述综述”，不是可完全复现的系统综述。
分类或命题逻辑三轴设计明显优于单一长短时分类，尤其能容纳潜在状态、参数内化和技能蒸馏。形态轴与动态轴较清晰，功能轴则同时混合知识类型、抽象程度和任务时域；混合系统如何被编码、是否允许多标签、不同标注者能否一致，没有报告。
竞争性解释某些被称为“记忆增益”的结果可能来自更长上下文、更强基础模型、额外推理计算、提示模板、工具编排或更优数据清洗，而不是记忆机制本身。论文的系统映射无法排除这些解释。

结论的适用条件

批判维度具体问题对结论的影响
隐性假设代理记忆是可从推理、上下文和参数知识中单独辨识的模块或能力；被纳入文献具有代表性；主导形态和功能可以稳定标注。若记忆与推理、规划、上下文编排不可分，三轴会更像观察者语言，而非系统的自然边界。
替代解释长程表现提升可能来自上下文扩展、测试时计算、模型规模、工具质量或任务专用提示；自我改进可能来自外部训练而不是记忆演化。会削弱“记忆机制带来能力”的因果含义，但不必然削弱分类框架的描述价值。
可反证路径建立统一代理骨干、相同令牌与算力预算、相同数据和任务，分别消融形成、演化和检索；用多标注者独立映射文献并报告一致性；在新出现方法上检验三轴是否仍能无歧义放置。若消融后性能无显著差异、标注一致性低或新方法持续落在分类之外，核心框架的机制和覆盖主张都会受损。

值得继续追问

  1. 召回了一条已经过期的经验时，系统如何发现并修正它？
  2. 在统一骨干、数据、令牌预算、延迟和算力成本下，形成、演化、检索三个模块各自贡献多少，是否存在可替代机制？
  3. 如果由多名研究者独立对同一批系统进行形态、功能和动态编码，三轴分类的一致性会有多高，哪些混合系统最容易破坏边界？
