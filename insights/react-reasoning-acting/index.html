把推理、动作和观察交替排列后，模型可以利用新证据修正计划。失败案例同样值得读，错误的检索结果也可能被后续步骤不断放大。

研究方法与证据

维度评估
研究设计论文覆盖知识密集任务与交互决策任务，能同时检验事实性、规划性和行动性，实验面较广
对照基线与 Standard，CoT，Act only，CoT self consistency 以及部分 imitation learning 和 reinforcement learning 方法比较，基线设置较充分
方法可解释性强。Thought，Act，Obs 结构天然形成轨迹日志，便于诊断失败原因
实证强度中高。ReAct 在 ALFWorld 和 WebShop 上优势明显，在 HotpotQA 和 Fever 上更体现互补性

结论的适用条件

可反证问题如果出现什么结果，论文主张会被削弱
Thought 是否真的驱动行动随机替换或隐藏 Thought 后，行动表现几乎不下降
外部观察是否真正降低幻觉工具观察可用时，幻觉率并未显著下降，甚至因错误检索更高
ReAct 是否适合长程任务任务长度增加后，重复循环、上下文丢失和错误传播迅速超过收益

值得继续追问

  1. 在行动轨迹的哪一步加入核对，能最早发现错误观察？
  2. Thought 到底是因果控制信号，还是一种对行动的可读包装？如何设计实验区分二者？
  3. 当工具观察存在噪声、过期或权限缺失时，ReAct 需要怎样的自检和纠错机制？
